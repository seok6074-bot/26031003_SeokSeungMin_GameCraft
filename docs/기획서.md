# 청소기 대소동 — 게임 기획서

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 게임명 | 청소기 대소동 |
| 장르 | 2D 탑다운 청소 액션 게임 |
| 개발 도구 | Visual Studio 2022, C# |
| 구현 환경 | Windows Forms 기준으로 계획. 수업의 프로젝트 조건에 따라 조정 |
| 플레이 인원 | 1명 |
| 배경 | 청소 로봇들이 고장 난 대형 창고 |
| 맵 | 큰 사각형 맵 하나 |
| 핵심 목표 | 제한 시간 안에 바닥 쓰레기의 80% 이상을 청소 |
| 핵심 특징 | 흡입한 쓰레기를 탄약으로 사용하며 청소와 전투 사이에서 선택 |

> 바닥을 청소하면 탄약이 생긴다. 로봇을 멈추려면 탄약을 써야 하지만, 빗나간 쓰레기는 다시 청소해야 한다.

## 2. 배경 및 플레이어 역할

창고의 자동 청소 로봇들이 고장 나 쓰레기를 뿌리고 있다. 플레이어는 흡입과 발사가 가능한 청소기를 들고, 로봇을 멈추면서 창고를 정리해야 한다.

이동과 방향 선택, 흡입, 발사가 플레이의 중심이다. 복잡한 이야기나 여러 스테이지보다 한 맵에서 목표가 분명한 짧은 플레이를 만드는 데 집중한다.

## 3. 승리와 패배 조건

- **승리:** 제한 시간 안에 청소율 80% 이상에 도달하면 즉시 클리어한다.
- **패배:** 플레이어의 체력이 0이 되거나, 청소율 80%에 도달하지 못한 채 제한 시간이 끝난다.
- 로봇을 전부 처치할 필요는 없다. 로봇 처치는 청소를 쉽게 만드는 수단이다.

### 청소율 계산

최초 쓰레기는 50개로 시작하고, 현재 바닥에 남은 쓰레기가 10개 이하이면 승리한다.

`청소율 = (최초 쓰레기 수 - 현재 바닥 쓰레기 수) / 최초 쓰레기 수 × 100`

표시 값은 0~100%로 제한한다. 로봇이 새로 떨어뜨린 쓰레기와 빗나간 탄환이 남긴 쓰레기도 현재 바닥 쓰레기에 포함한다. 따라서 청소율은 다시 낮아질 수 있다.

승리 판정에는 비행 중인 플레이어 탄환도 남은 쓰레기로 계산한다. 탄환을 발사한 순간에만 청소율이 올라 클리어되는 상황을 방지한다. 로봇에 명중한 탄환은 제거된다. 청소기 안에 보관 중인 쓰레기는 청소한 것으로 인정한다.

## 4. 기본 플레이 흐름

1. 시작 화면에서 조작과 목표를 확인하고 게임을 시작한다.
2. 맵을 돌아다니며 쓰레기를 흡입해 청소율과 탄약을 늘린다.
3. 다가오는 로봇을 피하거나 쓰레기를 발사해 고장 낸다.
4. 빗나간 쓰레기는 다시 흡입하고, 로봇이 더럽힌 구역도 정리한다.
5. 청소율 80%에 도달하면 결과 화면에서 기록을 확인한다.
6. 재시작을 선택하면 모든 상태를 초기화하고 다시 플레이한다.

## 5. 조작

| 입력 | 동작 |
|---|---|
| W / A / S / D | 상하좌우 이동 |
| J 누르기 유지 | 바라보는 방향의 쓰레기를 연속 흡입 |
| K | 바라보는 방향으로 쓰레기 발사 |
| Esc | 일시정지 / 계속하기 |
| 결과 화면의 재시작 버튼 | 게임 재시작 |

- 마지막으로 이동한 방향을 바라보는 방향으로 기억한다.
- 이동은 대각선도 허용하되 속도는 상하좌우 이동과 같게 보정한다.
- 공격과 흡입 방향은 상하좌우 네 방향으로 제한한다. 두 이동키를 함께 누르면 마지막으로 누른 방향을 사용한다.
- J와 K를 동시에 입력하면 발사를 우선하며 해당 순간에는 흡입하지 않는다.

## 6. 핵심 시스템

### 6.1 이동

- 플레이어는 맵 안에서 자유롭게 상하좌우로 움직인다.
- 맵 바깥과 장애물을 통과할 수 없다.
- 점프, 중력, 발판 착지는 구현하지 않는다.

### 6.2 흡입

- 캐릭터 앞쪽의 짧은 사각형 범위 안에 있는 쓰레기를 흡입한다.
- 일정 간격마다 가장 가까운 쓰레기 한 개를 제거하고 탄약을 한 개 늘린다.
- 로봇과 장애물은 흡입할 수 없다. 장애물 너머의 쓰레기도 흡입하지 않는다.
- 탄약 보유량에는 상한을 두지 않는다. 탄약이 가득 차 청소를 못 하는 상황을 피한다.
- 흡입 범위를 옅은 색으로 표시해 어디까지 청소할 수 있는지 알린다.

### 6.3 발사

- 탄약 한 개를 소비해 직선으로 이동하는 탄환 한 개를 발사한다.
- 탄약이 없으면 발사하지 않으며 HUD의 탄약 숫자를 잠깐 강조한다.
- 로봇에 명중하면 피해를 주고 탄환은 사라진다.
- 벽이나 장애물에 닿거나 최대 사거리에 도달하면, 마지막으로 통과 가능한 위치에 쓰레기로 남는다.
- 발사에는 재사용 대기 시간이 있다. K를 유지하면 해당 간격으로 발사해도 된다.
- 첫 버전에는 밀치기, 반사, 폭발, 다양한 탄종을 넣지 않는다.

### 6.4 로봇

첫 버전은 한 종류의 로봇만 사용한다.

| 행동 | 규칙 |
|---|---|
| 추적 | 플레이어 방향으로 이동한다. 플레이어보다 느리다. |
| 오염 | 일정 간격마다 자기 주변의 빈 바닥에 쓰레기를 한 개 떨어뜨린다. |
| 접촉 | 플레이어와 닿으면 체력 한 칸을 감소시킨다. |
| 피격 | 색이 잠깐 바뀌어 피해를 입었음을 보여준다. |
| 고장 | 체력이 0이면 사라지고 더 이상 쓰레기를 생성하지 않는다. |

- 로봇은 맵 시작 시 정해진 수만 배치하며 기본 버전에서는 추가 생성하지 않는다.
- 쓰레기는 장애물 안이나 맵 밖에 생성하지 않는다.
- 바닥 쓰레기 수에 상한을 두어 계속 늘어나지 않도록 한다.
- 장애물 사용 시에는 한 축이 막히면 다른 축으로 이동하는 단순 회피를 적용한다. 복잡한 길 찾기는 확장 범위로 둔다.

### 6.5 체력과 무적 시간

- 플레이어는 체력 5칸으로 시작한다.
- 로봇과 접촉하면 한 칸 감소하고 1초 동안 추가 피해를 받지 않는다.
- 무적 시간에는 캐릭터를 깜빡이게 표시한다.
- 기본 버전에서는 회복 아이템을 넣지 않는다.

## 7. 맵 구성

### 최종 목표

- 큰 사각형 창고 맵 하나를 사용한다.
- 예시 크기는 1,600 × 1,200이며, 게임 화면에는 그중 일부가 보인다.
- 카메라는 플레이어를 따라가되 맵 밖을 보여주지 않는다.
- HUD는 카메라와 관계없이 화면 위쪽에 고정한다.
- 쓰레기를 전역에 배치하고 시작 위치 주변에는 적이 없는 안전 공간을 확보한다.
- 모서리와 통로의 쓰레기가 모두 접근 가능한 위치인지 확인한다.

```text
┌──────────────────────────────────┐
│ 쓰레기 구역          로봇         │
│                                  │
│      상자             상자       │
│                                  │
│           넓은 중앙 공간         │
│                    로봇          │
│      상자                        │
│ 시작 위치            쓰레기 구역 │
└──────────────────────────────────┘
```

### 구현 순서

먼저 한 화면에 들어오는 빈 사각형 맵에서 청소와 전투를 완성한다. 그다음 맵을 넓히고 카메라 이동을 적용한다. 상자는 마지막에 소수만 추가하고, 좁은 미로나 막힌 구역은 만들지 않는다.

## 8. 재미를 만드는 선택

### 청소와 전투의 연결

쓰레기를 흡입하면 목표 달성과 탄약 확보가 동시에 이루어진다. 쓰레기는 제거해야 할 대상이면서 로봇을 멈추는 자원이 된다.

### 당장 청소할지, 로봇부터 멈출지

로봇을 무시하면 가까운 쓰레기를 빠르게 치울 수 있지만 오염이 계속된다. 먼저 로봇을 멈추면 시간과 탄약이 들지만 이후 청소가 쉬워진다.

### 정확하게 공격할 이유

명중한 쓰레기는 사라지고 빗나간 쓰레기는 다시 바닥에 남는다. 무작정 발사하기보다 적을 유인하고 방향을 맞춰 쏘는 것이 유리하다.

### 명확한 마지막 목표

청소율 70%부터 진행 막대를 강조한다. 남은 쓰레기를 찾기 어렵지 않도록, 화면 밖에서 가장 가까운 쓰레기 방향을 표시하는 기능은 확장 항목으로 둔다.

## 9. 화면 구성

| 화면 | 표시 내용 |
|---|---|
| 시작 | 제목, 목표, 조작법, 시작 버튼 |
| 플레이 | 맵, 캐릭터, 로봇, 쓰레기, 탄환 |
| HUD | 체력, 청소율, 남은 시간, 탄약 수 |
| 일시정지 | 계속하기, 처음부터 다시 시작 |
| 결과 | 성공 또는 실패, 청소율, 플레이 시간, 고장 낸 로봇 수, 재시작 버튼 |

HUD 예시: `체력 ♥♥♥♥♡ | 청소율 64% | 남은 시간 01:25 | 탄약 12`

체력 0과 승리 조건이 같은 업데이트에서 발생하면 패배를 우선한다. 체력이 남아 있다면 해당 업데이트의 청소 결과를 먼저 판정하고, 목표 미달일 때 시간 초과를 판정한다.

## 11. C# 구현 구상

### 주요 클래스

| 클래스 | 역할 |
|---|---|
| GameForm | 입력, 화면 그리기, 게임 업데이트, 화면 전환 |
| Player | 위치, 방향, 체력, 탄약, 흡입·발사 대기 시간 |
| Robot | 위치, 체력, 추적, 쓰레기 생성 |
| Trash | 바닥 쓰레기의 위치와 판정 영역 |
| Projectile | 위치, 방향, 이동 거리, 충돌 처리 |
| Obstacle | 이동과 탄환을 막는 영역 |
| Camera | 맵 좌표를 화면 좌표로 변환 |

### 기본 방식

- WinForms의 Timer로 게임 상태를 갱신하고 화면을 다시 그린다.
- 실제 경과 시간을 이용해 이동 거리와 제한 시간을 계산한다.
- KeyDown과 KeyUp으로 키의 눌림 상태를 기록해 이동과 공격을 함께 처리한다.
- OnPaint에서 캐릭터와 오브젝트를 그리고, 더블 버퍼링으로 깜빡임을 줄인다.
- 충돌은 사각형 판정을 기본으로 사용한다.
- 모든 충돌과 위치는 맵 좌표에서 계산하며, 그릴 때만 카메라 위치를 뺀다.
- 쓰레기, 로봇, 탄환은 각각 목록으로 관리한다. 제거는 순회 중 오류가 나지 않도록 처리한다.
- 게임 상태는 시작, 플레이, 일시정지, 성공, 실패로 구분한다.
- 일시정지 중에는 이동, 탄환, 로봇 생성 주기, 제한 시간 모두 멈춘다.

## 12. 개발 단계와 범위

| 단계 | 구현 내용 | 완료 기준 |
|---|---|---|
| 1 | 플레이어 이동, 화면 경계 | 여러 키를 눌러도 정상 이동하며 밖으로 나가지 않음 |
| 2 | 쓰레기 배치, 흡입, 청소율 | 흡입 시 쓰레기가 제거되고 탄약과 청소율이 반영됨 |
| 3 | 발사, 탄환 충돌 | 명중하면 로봇이 피해를 받고, 빗나가면 쓰레기로 남음 |
| 4 | 로봇 추적, 접촉 피해, 오염 | 추적과 쓰레기 생성이 작동하고 무적 시간이 적용됨 |
| 5 | 시간, 승패, 재시작 | 한 판을 시작부터 종료까지 진행하고 다시 시작할 수 있음 |
| 6 | 큰 맵과 카메라 | 맵 가장자리에서도 화면과 충돌 위치가 일치함 |
| 7 | 연출과 조정 | 흡입 범위, 피격 표시, HUD가 명확하고 난이도가 적절함 |

### 필수 제출 범위

큰 사각형 맵 하나, 상하좌우 이동, 흡입과 발사, 로봇 한 종류, 체력, 제한 시간, 청소율, 승패와 재시작을 구현한다.

### 시간이 남으면 추가

- 소수의 상자 장애물
- 발사음, 흡입음, 피격음
- 가장 가까운 쓰레기 방향 표시
- 남은 시간과 체력에 따른 별 등급
- 돌진 로봇 한 종류

### 첫 버전에서 제외

멀티플레이, 여러 스테이지, 보스, 상점, 장비 강화, 복잡한 물리 흡입, 절차적 맵 생성은 넣지 않는다.

- 대각선으로 이동할 때 속도가 빨라지지 않는가?
- 탄약이 없을 때 음수가 되거나 탄환이 생성되지 않는가?
- 탄환 하나가 로봇 여러 대에 중복 피해를 주지 않는가?
- 빗나간 쓰레기가 접근 불가능한 곳에 떨어지지 않는가?
- 비행 중인 탄환을 포함해 청소율과 승리 조건이 일관적인가?
- 접촉 상태가 지속되어도 무적 시간 동안 체력이 추가로 줄지 않는가?
- 카메라가 움직여도 공격과 충돌 위치가 정확한가?
- 일시정지와 재시작 시 타이머와 오브젝트 상태가 올바르게 처리되는가?
- 처음 하는 사람이 목표를 이해하고 제한 시간 안에 클리어할 수 있는가?

## 14. 발표용 소개

청소기 대소동은 쓰레기를 흡입해 탄약으로 사용하고, 고장 난 로봇을 상대하며 창고를 청소하는 2D 탑다운 액션 게임이다. 플레이어는 제한 시간 안에 쓰레기의 80% 이상을 제거해야 한다. 로봇을 방치하면 오염이 늘고 공격이 빗나가면 쓰레기가 다시 남기 때문에, 청소와 전투의 우선순위를 판단하는 것이 핵심이다.
