# 청소기 대소동 · 4차 기말 기획서

## 게임 개요

플레이어는 고장 난 청소 로봇이 돌아다니는 창고에서 쓰레기를 치웁니다. 흡입한 쓰레기는 발사 탄약이 됩니다. 로봇을 견제하는 데 탄약을 쓸지, 청소에 집중해 빨리 목표를 달성할지 판단하는 1인용 탑다운 액션 게임입니다.

## 한 판의 흐름

시작 화면에서 목표와 키를 확인하고 시작합니다. 창고를 이동하며 쓰레기를 흡입하고, 필요할 때 로봇을 향해 발사합니다. 3분 안에 청소율 80%에 도달하면 승리합니다. 체력이 모두 소진되거나 시간이 끝나면 실패합니다. 결과 화면에서 청소율, 플레이 시간, 멈춘 로봇 수를 확인한 뒤 재시작할 수 있습니다.

| 조작 | 기능 |
|---|---|
| Enter | 시작 또는 재시작 |
| WASD | 이동. 마지막으로 누른 이동 방향으로 조준 |
| J | 누르는 동안 앞쪽 쓰레기 흡입 |
| K | 탄약 발사. J와 동시에 누르면 발사 우선 |
| Esc | 일시정지 또는 계속 |
| R | 일시정지·결과 화면에서 재시작 |
| M | 배경음악과 효과음 켜기·끄기 |

## 게임 규칙

- 창고는 1,600 × 1,200 크기입니다. 쓰레기 50개, 체력 5칸, 탄약 0개, 로봇 4대로 시작합니다.
- 흡입 범위는 전방 112픽셀, 좌우 각 43픽셀입니다. 장애물 뒤 쓰레기는 흡입할 수 없습니다. 가까이 끌려온 쓰레기를 수거하면 탄약 1개를 얻습니다.
- 탄약이 로봇에 명중하면 사라집니다. 벽에 부딪히거나 사거리를 다 쓰면 바닥에 쓰레기로 남습니다. 청소율은 초기 50개를 기준으로 현재 바닥 쓰레기와 비행 중 탄환을 제외한 비율입니다.
- 로봇은 플레이어를 추적하고 10초마다 주변에 쓰레기를 떨어뜨립니다. 탄환 3발을 맞으면 멈춥니다. 12초마다 창고 가장자리에서 로봇이 추가되며 최대 6대까지 활동합니다.
- 로봇과 부딪히면 체력을 한 칸 잃고 1초 동안 추가 피해를 받지 않습니다. 같은 순간에 여러 종료 조건이 충족되면 체력 소진, 청소율 달성, 시간 초과 순으로 판정합니다.

## 화면과 소리

체력, 제한 시간, 탄약, 청소율, 로봇 수와 다음 등장 시간은 플레이 중 화면에 표시합니다. 미니맵에는 플레이어, 쓰레기, 로봇 위치를 표시합니다. 카메라가 플레이어를 따라가고 쓰레기는 흡입 시 노즐 쪽으로 이동합니다. 배경음악은 32초 길이로 반복되며 일시정지 시 멈췄다가 이어집니다.

## 한 판 검증 기록

게임의 실제 규칙 코드에 자동 플레이 입력을 넣어 타이틀 상태에서 시작하고 종료 조건까지 1판을 진행했습니다. 상태나 체력, 점수를 강제로 바꾸지 않았습니다.

| 기록 | 결과 |
|---|---|
| 결과 | 승리 |
| 플레이 시간 | 18.3 초 |
| 청소율 | 80% |
| 남은 체력 | 5 / 5 |
| 흡입한 쓰레기 | 42 개 |
| 발사 횟수 | 9 회 |
| 멈춘 로봇 | 2 대 |
| 접촉 피해 | 0 회 |

위 기록은 자동 플레이에 따른 규칙 검증입니다. 제출용 실행 파일의 화면 조작을 직접 수행한 기록은 아닙니다.
